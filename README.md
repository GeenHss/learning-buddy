# Rekenhelden

A small learning app for young children: maths (sums, number splits, telling time), reading (sounds and words) and writing. Dutch and English.

Everything runs in the browser. Progress is stored only on the device (no accounts, no server).

## Install on an iPad
1. Open the GitHub Pages address in **Safari**.
2. Tap **Share → Add to Home Screen**.
3. Open the app from the home screen and create a profile for each child.

## Updating
Replace `index.html`, and change `VERSION` in `sw.js` (e.g. `v1` → `v2`) so installed apps pick up the new version.
